# 0300 — The run tightens no lattice

- **Date:** 2026-09-03
- **Status:** accepted, amending [0278](0278-the-rack-shapes-the-picture.md) and standing under
  [0298](0298-every-automator-tears-the-torn-picture.md)

**The lattice reads the hand-added rack alone.** `shapeTravelInto` (src/ui/moireShape.ts) takes
no run any more: `latticeCells(toward.standing)`, where `rackShape` already skipped every entry
that grows. The places an automator's run is standing were summed in beside the hand-added
entries, so a run filling to six tightened the cell from its loosest to its tightest — and the tear
the same automator cuts (0296–0298) throws a periodic weave sideways, which at four cells a height
is the same weave with a hairline in it. Shot off a click-train yard holding one filter and one
automator through a headed browser, at a run of one the picture is the coarse lattice broken into
strips at unrelated offsets; at six it was a fine even texture that the tear switched off, doubled
in reach or widened to four cycles a piece all left indistinguishable, and with the run out of the
lattice a run of six is torn as a run of one is. What the run holds is still drawn: its rows, its
octaves and the depth its feedback earns all read `runStanding` as before (0204, 0250) — it is only
the cell the run no longer asks anything of.
