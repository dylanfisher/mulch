# 0140 — A hidden gesture is armed, said and shown

- **Date:** 2026-08-24
- **Status:** accepted, extending
  [0138](0138-the-drift-opens-a-window-the-instrument-drives.md) and
  [0139](0139-a-row-is-what-an-effect-is-set-to.md)

The window costs two gestures. A performer who wants the drift beside the instrument rather than
over it has to zoom it over the instrument first and then pop it out, which is the covering 0138
exists to end, done once on the way every time.

**Option on the strip is the shortcut straight to the window, and a shortcut owes three things.**
_Armed_ on the modifier the instrument already arms on — Option, the same one a knob records under
(0024) — because a second modifier for a second meaning is a vocabulary nobody keeps. _Said_ in the
sentence on the pop-out button, which is the one surface that already explains where the picture
can go, so the gesture is written down exactly once (`MOIRE_POP_OUT_TOOLTIP`, principle 1); a
gesture nothing says is a gesture nobody finds. _Shown_ while the modifier is down, by the strip's
cursor turning from the zoom to the alias arrow — the one cursor a browser has for "this goes
somewhere else".

**The press reads the event's own modifier, not the reveal.** The reveal is React state a render
behind, and a click made in the same instant Option goes down would zoom while the cursor said it
would not. The cursor is a promise about the next press; the press is decided by the press.

**A shortcut may not be a control that cannot work.** Where a browser has already refused a window,
there is no straight route, so an Option press zooms like every other one (0138) — and the strip is
not armed at all, because an arrow promising a window nothing will open is worse than no arrow.
