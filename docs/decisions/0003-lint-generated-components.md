# 0003. Relax a fixed set of lint rules inside `src/ui/components`

- **Date:** 2026-08-12
- **Status:** accepted

Turn off a fixed list of a11y/style lint rules for `src/ui/components/**` only (via an `.oxlintrc.json` override), since that directory is regenerated by `pnpm shadcn add` and hand-fixing it would be lost on the next regen; `react-perf/jsx-no-jsx-as-prop` is disabled repo-wide because Base UI's `render={<X />}` composition API requires it everywhere. The list is closed: a new generated component that trips a rule not on it fails the gate rather than quietly widening the exemption.
