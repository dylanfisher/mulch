# 0210 — A run is a size range, and the floor beats the odds

- **Date:** 2026-08-29
- **Status:** accepted, extending [0204](0204-a-run-is-laid-on-the-automation-horizon.md)

An automator's run is a floor, a ceiling and the odds a turn lays anything: `Least`, `Most` and
`Odds` where `Held` used to be one number. `Most` is how many places there are — a place lives
exactly that many ticks, which is what the life and the turnover are still divided by — and how
many of them are filled is what breathes. Nothing durable moved but the three declarations, because
a value is already `(instance, param)` ([0030](0030-effects-are-instances.md)), and what no longer
validates is discarded rather than migrated ([0026](0026-pre-release-has-no-migrations.md)).

**The floor beats the odds.** A tick that would leave fewer than `Least` places standing lays
whatever the roll said. A bound is a promise and a chance is a texture: a floor that a run of bad
luck could fall through would be neither, and the same rule read on the way up is what keeps the
opening one arrival per tick rather than a set. `Least` above `Most` is `Most`, not an empty run.

**The roll is spent at every tick and whatever it says**, before the draws it precedes, so a seed
still names one performance ([0134](0134-a-pattern-plays-the-repeats-it-was-set.md), 0204). It is
not a wander's roll, which spends its draw and then declines to use it: this one gates the lay, and
a tick that lays nothing spends nothing on an entry — so a thinned run is a different population
from the same seed rather than the full one with places missing. One draw joined the stream either
way, so a seed unfolds a different population than it did before this build.

**Only `Most` reaches the picture.** It is the swarm's depth, which is what `Held` claimed; a floor
is that same swarm on the ticks the odds thinned, and how often a place is filled is the same run
happening less often — neither is a shape, so both are written down as unreached rather than given
a dimension ([0148](0148-a-parameter-is-reached-or-it-is-written-down-as-not.md)).
