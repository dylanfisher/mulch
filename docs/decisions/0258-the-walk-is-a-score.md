# 0258 — The walk is a score, and the slot is in the readout

- **Date:** 2026-09-01
- **Status:** accepted, replacing the reading in
  [0187](0187-the-walk-is-a-sheet-and-it-turns-over.md) rather than the sheet itself; the argument is
  `SketchScore` on the bench ([0254](0254-the-bench-argues-the-card-fold-by-fold.md))

The scope drew each landing on the band of the slot it read: sixteen bands, slot nought at the
foot, and a thread from one landing to the next. It now draws each landing **standing on the floor,
as tall as it is struck often** — one rung per doubling of the count, ruled at 1, 2, 4, 8, 16, 32
and 64, which is the repeat dial's own range — with the loop's own turnovers ruled across it.

**What that buys.** The count was the one thing about a landing the picture could not say. A sheet
of twenty-four landings gave each of them a band a few pixels deep, and how many bursts one was cut
into was legible only as split marks too fine to count. As a height it is legible at a glance, and
two patterns with the same landings and different counts are now two pictures. The bars are the
other half: the sheet's across is wall seconds, so without the loop ruled across it a cluster and a
long hold are the same width and there is no beat to read a rhythm against.

**What it costs.** Where each jump _lands_ is no longer on the picture, and with it goes the thread
between two landings — a line between two rung heights says nothing. So `distance`, `bias` and
`home` cannot be read off the sheet any more. They could not be turned there either (0232), and the
slot is now a number in the readout a press opens (0257), which is where the picture had no room for
it in any case. The ground moving keeps its mark, as a dashed hairline standing where it moved
rather than as a break in a thread that no longer exists.

**The scale is fixed at the dial's ceiling, never at the sheet's own tallest.** A picture scaled to
what happens to be on it would make one pattern two pictures on two sheets, which is the rule the
sheet's width is already fixed by (0098). A landing struck once stands one rung and never at
nothing: it happened, and a block of no height is a landing the picture did not draw.
