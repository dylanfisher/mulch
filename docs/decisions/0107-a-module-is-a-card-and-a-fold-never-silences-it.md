# 0107 — A module is a card, and a fold never silences it

- **Date:** 2026-08-21
- **Status:** accepted

Everything a yard holds that has knobs is a card: a `Card` in the rack's own language, its heading
the toggle that folds it (0106), its dials at the rack's size with the two line boxes every
caption spends (0093), and a sentence on every control that does something (0094). The jumps
module was a bare row of `xs` knobs and is now that card; anything added beside it is one too.

The card's two switches are never the same switch. Folding is a view preference — no command,
nothing durable, no history entry — and the durable switch that holds or clears the module's spec
stays in the head while it is folded, so putting a module away and silencing it remain two
gestures. A module offering only the durable one has no way to be put away except by being turned
off, which is the defect this rules out.

The word on that heading is a noun for what the module does, decided in `src/lib/copy.ts` with the
rest of the instrument's words. "Player" named no behaviour — every yard plays — so the module
that moves where inside its loop a deck reads from (0089) is called Jumps, and its knobs carry
their own sentences rather than borrowing another control's — as does its reseed, which now has a picture of
its own too, because an action that borrows the picture borrows the words with it (0055).
