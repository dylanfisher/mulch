# 0005. The catalogue is a grep, not a document

- **Date:** 2026-08-12
- **Status:** accepted

Every file under `src/` carries a one-line `@role` (and optional `@instead`) comment that `./scripts/map` greps into a catalogue and `./scripts/map --check` enforces as the `roles` step of `./scripts/check`, instead of maintaining a hand-written catalogue document; `src/ui/components` is exempt since it is regenerated by `shadcn add`.
