# 0274 — A loop is a ground

- **Date:** 2026-09-01
- **Status:** accepted, amending
  [0235](0235-a-ground-move-is-travelled-not-written.md), on
  [0273](0273-the-picture-travels-with-the-song.md)

0235 travelled the field to a moved ground and left the ground to the jumps module: a yard that is
not jumping "has no landing and no ground move", and its rows stood in the middle of the picture.
So a hand dragging the loop across the file moved nothing but the phases, which restacked in place —
and once the rows travel several fringes a turn (0273) that restack is the one motion in the
picture that reads as a jump rather than a journey.

**A loop is a place the yard really is reading, so it is a ground.** `loopStand` anchors a yard
whose walk is standing nowhere on its loop's own in-point, through the same arithmetic the walk's
ground is measured with, so a ground of zero inside the loop and the loop itself are one anchor.
Only a yard with no loop at all rests in the middle.

**And its move is travelled over half the loop.** The one length a loop's move can be a fraction
of is the loop, which is the reference row's own period — so `groundTravel` falls back to that row
where there is no tier row, on 0235's rule that the ease finishes inside the thing it is about: a
loop nudged a beat along slides, and one dragged across the file sweeps. Only while the yard
sounds, for the ink's reason (0144): a halted picture is painted on a commit, and a loop moved on
a stopped yard arrives outright rather than stranding the field mid-travel.

Durable shape: none.
