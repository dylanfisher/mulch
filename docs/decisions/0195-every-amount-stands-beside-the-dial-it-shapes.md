# 0195 — Every amount stands beside the dial it shapes

- **Date:** 2026-08-28
- **Status:** accepted, retiring the door
  [0121](0121-a-framed-plus-is-a-door.md) opened and P135 laid inline, and
  keeping what [0124](0124-a-drawn-number-carries-the-amounts-that-shape-its-draw.md) said about
  _which_ amounts belong to which dial.

**Nothing on the mulcher card is behind a press.** Every number the module declares is drawn at
once, in the box its question belongs to, with each dial's amounts standing beside it in a tinted
run (`PlayerRun`). The marker that opened a set, the count on it, the one-open-at-a-time set the
yard held and the Escape that shut it are all gone: a control a hand cannot see is a control it
does not have, and the count on a corner said how many were hidden without making any of them
reachable in one gesture.

**What the run keeps is ownership, not concealment.** 0124's partition is untouched — a bed's
distance still belongs to Every, a climb still belongs to Hold — and the tint that brackets a dial
with its amounts is what says so on screen. The set each run draws is still the one declared in
`playerKnobs.ts` (`PLAYER_RUN_KNOBS` and its parts), so a knob is drawn in exactly one place.

**An amount is named for the dial it shapes.** A caption is a dial's whole accessible name, and six
dials captioned Chance on one card would be six sliders nothing — a screen reader, a locator,
`./scripts/drive` — could tell apart. So an amount's accessible name is its dial's word and then
its own: "Phrase Chance", "Rate Spread", "Every Distance", with a part's fold putting the part in
front of both (`runName`, 0176). The visible caption stays the one word it was, because the run it
stands in already says which dial it belongs to.

**The cast and the clock stand inline too.** The arrangement's six cast presses were the one set
kept in a popover, on the ground that a block of presses beside dial columns reads as a different
grammar. The ground's own clock had already been laid inline under an eyebrow of its own (0192) and
reads perfectly well there, so the cast follows it rather than being the last thing on the card a
hand has to find.

**The card is taller, and that is the trade.** Four full-width boxes of about forty controls is more
to read than fourteen with markers on them — but the module's vocabulary was always that size, and
the height is paid once, in a card that folds (0107), rather than paid by every hand that never
found the amounts at all.
