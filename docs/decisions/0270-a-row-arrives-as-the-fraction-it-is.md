# 0270 — A row arrives as the fraction it is

- **Date:** 2026-09-01
- **Status:** accepted, on
  [0139](0139-a-row-is-what-an-effect-is-set-to.md) and
  [0235](0235-a-ground-move-is-travelled-not-written.md)

Adding an effect flashed the whole picture. What it weighs is solved for how many rows it has
(`gratingDepth`), so an added row moved every other row's depth between two frames, and the row
itself was cut at its whole depth on the first frame it existed. Removing one did the same thing
backwards. None of that is a reading of anything: it is the count changing in one step.

**A row carries how much of the picture it is, and it is the fourth accumulated number in the
drift.** The other three are the field's — the ground the rows stand on, the plane the structure
travels across, the ink it is drawn in — and this one is a row's. A row is _built_ wholly in the
picture, so the first set a picture ever holds is drawn outright; a rebuild is what admits anything
slowly, because a rebuild is exactly what an effect arriving or retiring already is.

**The carry is what makes an arrival an arrival** (`carryArrivals`). It matches a fresh set against
the one it replaces by each row's own name — never by index, which shifts under a removal and would
hand a row a stranger's share — stands a row nobody held yet at nought, and keeps a row nobody holds
any more in the picture, marked leaving, until it has finished leaving. A row wholly gone is dropped
at the next rebuild.

**The share is spent in three places and the three agree**: how deep the row cuts (`washedDepth`),
what the picture weighs (`drawnGratings`) and whether the row's claim carries the ink
(`boldestRow`). `gratingDepth` is continuous in its count, so a row arriving as a quarter moves the
picture a quarter of the way — which is the same argument 0213 already made for the wash's own row
and the session's, applied to every row there is.

Six seconds, the length the wind takes to turn (0267), because an effect added is one event and the
picture answers it with one motion. Arrives outright on a yard that is not sounding, for the reason
the ink and the wind both do: a halted picture is painted on a commit and not on a frame (0144).

Refused: fading a row's _depth_ in without moving the count. That leaves the picture's weight
restacking on the frame the row appears — the flash is the count, not the row.
