# 0069. The palette is a second way to send, and a shared gesture builds its command in one place

- **Date:** 2026-08-16
- **Status:** accepted

P41's palette offers a gesture the instrument already has a control for, which is the whole risk in it: two surfaces, two constructions, and a drift nobody sees until a replayed session is missing an emoji. So the constructions moved. `src/ui/actions.ts` holds the command for every gesture more than one surface offers — `deck.add` with its minted id and its two drawn pools, `clip.capture` with its minted id and its numbered name, `effect.add` with its fresh instance id, and the three one-line transports — and the button, the key and the palette entry all call it. Nothing reaches past `send()`, and the palette owns no command of its own: an entry is a label, an icon and a call to one of those builders. A gesture only one control offers still builds its command at that control (principle 3).

The three entries that are not commands are the same rule for view preferences (§2): Export Session calls `exportSession` in `src/ui/FileMenu.tsx`, the theme steps through `setTheme` by `nextTheme`, and the debug console entry _is_ `toggleDebugConsole` by identity. Export Audio moved its dialog up to the shell, because two surfaces open it and two dialogs would be two boxes in one corner. A gesture's _in-flight_ state moved with its construction for the same reason: `exportSession` holds the one archive being written, because the menu disables its own entry while it runs and the palette — which closes the moment an entry is chosen — has nowhere to hold that guard. The proof is `src/ui/CommandPalette.test.tsx`: with the minted ids and the drawn pools pinned, each entry and the control offering the same gesture are compared with `toEqual`, so a copied construction fails the moment either side changes.

**`cmdk` is refused.** shadcn's `command` recipe is a wrapper over it, and a new dependency needs approval (principle 7). It is not needed: the Base UI build the style generates from ships `Autocomplete`, with the filter, the highlight, the listbox roles and an `inline` mode that renders no popup of its own — so the palette is that primitive inside the dialog the app already has, opening with `duration-0` on both halves like every other overlay the driver touches (0056). ⌘/Ctrl+K is read in `src/ui/shortcuts.ts` ahead of the editable guard, and it is the only key that is: a palette is how someone who cannot find a control reaches it, so it has to answer from inside a rename field and from inside its own filter box.
